Responsive QA report

S2: mobile CTA row overflows the viewport

Environment: Chromium, 390 × 844 viewport, Windows 11 local fixture.

Reproduce

  1. Open the demo at 390px wide.
  2. Scroll to the hero CTA row.
  3. Observe the fixed-width buttons and horizontal overflow.

Expected / actual

Expected: controls fit, remain readable and preserve a clear primary action.

Actual: the row exceeds the viewport; the primary action is partly hidden.

Recommended fix

Use a responsive flex/grid layout, allow buttons to wrap or stack, and re-test at 320px, 390px and 430px.

This is a demonstration fixture, not a client result.
